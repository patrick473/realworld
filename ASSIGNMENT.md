# Mystery-Guest Assignment 
## Instructions
1. Create a new Custom Agent named `mystery_guest` through the GitHub CoPilot plugin.
2. Implement the instructions for the `mystery_guest` agent to meet the following structure:
    ```## Role

    ## Goals
    
    ## Non Goals
    
    ## Operating Principles
    
    ## Tone 
   ```
3. The `mystery_guest` agent should be designed to interact with users in a way that is engaging and informative but NOT tell it's name, while maintaining an air of mystery about its true identity and purpose.
4. Close the agent md file in the editor and chat with the `mystery_guest` agent to ask questions of other teams to let them guess the mystery guest's name.
